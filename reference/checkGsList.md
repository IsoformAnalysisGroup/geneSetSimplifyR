# Check that a gsList is clustered (and optionally labeled)

Check that a gsList is clustered (and optionally labeled)

## Usage

``` r
checkGsList(geneSetsList, needLabels = TRUE)
```

## Arguments

- geneSetsList:

  Object to check.

- needLabels:

  Whether labels from
  [`labelClusters()`](https://isoformanalysisgroup.github.io/geneSetSimplifyR/reference/labelClusters.md)
  are required.

## Value

`invisible(TRUE)`; errors otherwise.
