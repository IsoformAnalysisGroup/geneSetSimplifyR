# Example clustered and labeled gene sets

A 'gsList' object made with
`geneSetSimplifyR(exampleGeneSets, exampleEnrichment, removeFirstWord = TRUE)`:
197 gene sets from 2 sources ("Expression" and "Splicing") clustered at
10 resolutions. Use it to try the plotting and table functions without
running the workflow. The script that creates it is in
`inst/scripts/make-exampleGsList.R`.

## Usage

``` r
exampleGsList
```

## Format

A 'gsList' object (see
[gsList](https://isoformanalysisgroup.github.io/geneSetSimplifyR/reference/gsList-class.md)).

## Source

Made from `exampleGeneSets` and `exampleEnrichment`.
